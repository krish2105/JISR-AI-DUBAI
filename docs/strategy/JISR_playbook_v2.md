## 2. The project in one line

**Jisr AI** is a governed agent that turns an India-to-UAE buyer enquiry into an approved quote, a CEPA-optimised export document pack and a follow-up plan, and warns about trade risks before money moves.

**Why it can win:** it is a real workflow, with real pilot numbers, in a corridor that governments on both sides are pushing, and it solves the trust problem that stops companies from using agents.

## 4. Five moat features (what makes Jisr hard to copy)

1. **CEPA Duty Optimiser.** For each line item, the agent checks origin rules and flags where the UAE preferential duty could apply, estimates the saving, and lists the origin evidence needed. CEPA has been in force since 1 May 2022. A vendor page says the standard UAE rate was 5% before CEPA and the main origin test is 35% regional value content **(verify with official tariff and rules-of-origin texts)**. This is the demo "wow": *"Jisr found AED X of duty savings the quote would have missed."*
2. **Document Consistency Checker.** It cross-checks the invoice, packing list, origin certificate and shipping data for the mistakes that delay shipments: HS-code mismatches, missing origin certificate, missing export-tax declaration, direct-consignment gaps. These common mistakes come from a vendor guide **(verify)**.
3. **Buyer Trust Check.** It screens buyers against public sanctions lists and sanity-checks licence and company details, then flags risk before the quote goes out. Use only public lists and user-provided data, and always show it as a *signal for human review*, not a verdict.
4. **WhatsApp-native workflow.** Indian SMEs run on WhatsApp. The agent reads enquiries and drafts replies there, with approval before anything is sent. Meta has charged per message since July 2025. Replies inside the 24-hour customer-service window are free, template messages are paid, and AED billing exists from April 2026 **(verify current rates)**.
5. **Governance with an Agent Passport.** Each agent has a one-page passport: purpose, permissions, tools, data touched, risk class, limits. Together with the audit log, policy engine and kill switch, this becomes your Seal-readiness story and your answer to "can we trust it?".

**Not in scope (say no to these):** real payments, real customs filing, general chatbot features, full ERP.

## 13. Judge Q&A (extra questions for v2)

1. *How do you know the duty savings are right?* Retrieval from official texts, citations, a human check flag below a confidence threshold, and broker review of templates.
2. *Isn't customs software already solved?* Large platforms serve declarations. We serve the SME's enquiry-to-cash workflow with governance built in.
3. *Why should a Dubai buyer care?* Faster, clearer quotes and fewer document errors, which means faster clearance.
4. *What stops the agent from being tricked?* A deterministic policy engine sits outside the model, so even a fooled model cannot send or change anything without approval.
5. *Who owns the IP, and what happens to it after the prize?* The team owns it. DCDE has a promotional licence only.
6. *What will you do with AED 550,000?* Dubai entity and licence, paid pilots with 5 exporters, a customs-advisor retainer, hosting and model costs, one hire.
