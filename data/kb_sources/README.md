# Knowledge-base sources (official documents only)

Download these into this folder (files here are git-ignored; only this README is committed).
Record each file's **title, issuing body, URL and document date** in `sources.csv` (Phase 5).

1. GCC Common Customs Tariff / UAE HS nomenclature (latest edition)
2. India–UAE CEPA full text, **Chapter 3 Rules of Origin and the Product-Specific Rules annex**
3. DGFT notifications on CEPA certificates of origin (e.g. Public Notice 04/2022 and later updates)
4. Dubai Customs import procedure guides (documents required, origin certificate handling)
5. India export documentation guides (DGFT / ICEGATE: shipping bill, export declarations)
6. Incoterms 2020 summary (ICC public summary)
7. UAE VAT on imports basics (Federal Tax Authority guide)

Never use vendor blogs as KB sources. They may be used only to find the official document.
